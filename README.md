# Noir & Verse Apparel - Web Development Project

## Student Details
* **Module:** Web Development (WDFE5112 / WEDE5020)
* **Project Name:** Noir & Verse Apparel Prototype Website
* **Tech Stack:** HTML5, CSS3, JavaScript (Vanilla ES6), GitHub Pages

---

## Project Overview
Noir & Verse Apparel is an independent boutique clothing label blending vintage romance cinema, 35mm film photography, and written poetry into high-quality streetwear drops.

---

## Technical Features Implemented in Part 3

### 1. JavaScript Interactivity (`js/main.js`)
* **Client-Side Form Validation:** Prevents invalid form submissions on `enquiry.html` and `contact.html` by checking for empty input fields and valid email syntax via Regular Expressions.
* **Responsive Mobile Navigation:** Added a hamburger toggle button for seamless navigation on small mobile viewports.
* **Product Category Filter:** Implemented dynamic filtering buttons on `products.html` allowing users to view specific clothing items.

### 2. Search Engine Optimization (SEO) & Accessibility
* **Meta Tags:** Included `<meta name="description">`, `<meta name="keywords">`, and Open Graph social sharing tags across all 5 pages.
* **Semantic Structure:** Organized headings sequentially (`<h1>` through `<h4>`) to maintain content hierarchy.
* **Image Accessibility:** Assigned detailed `alt` text to every image tag for screen readers and SEO image search indexing.

### 3. Embedded External Services
* **Google Maps Embed:** Integrated an interactive map iframe on `contact.html` locating the brand's Cape Town pop-up store.
* **Spotify Playlist Embed:** Embedded an external music stream on `enquiry.html` to highlight the brand's mood boards and journal aesthetic.
